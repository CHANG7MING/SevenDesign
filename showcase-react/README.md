# React Showcase

This folder contains a standalone React demo page based on the CA7-DESIGN library.

## What it demonstrates

- `AI_NATIVE` + `DEVTOOL_PRO` flavor mix
- cinematic-but-usable hero
- matching internal product shell
- token-aware surface hierarchy
- premium pricing section without generic SaaS styling

## Files

- [`App.tsx`](./App.tsx)
- [`styles.css`](./styles.css)
- [`main.tsx`](./main.tsx)
- [`index.html`](./index.html)
- [`package.json`](./package.json)

## Intended use

Use this as:

- a visual reference for what the library can produce
- a starter page to port into a real React app
- a prompt target when asking AI to generate matching pages

## Run locally

```bash
npm install
npm run dev
```
