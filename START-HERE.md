# START-HERE

If you want to use this library immediately, start here.

This repository is a plug-and-play `DESIGN.md` library for:

- AI products
- developer tools
- backend / infrastructure products
- SaaS apps
- docs systems
- pricing pages
- premium landing pages

You do not need to read every file.

## Fastest Path

### Option 1: Use it with AI right now

1. Start with the unified router [`skills/seven-design/SKILL.md`](./skills/seven-design/SKILL.md)
2. Add [`skills/emil-design-eng/SKILL.md`](./skills/emil-design-eng/SKILL.md) for the default craft bar
3. Add [`skills/apple-design/SKILL.md`](./skills/apple-design/SKILL.md) for fluid or gesture-driven UI, or [`skills/review-animations/SKILL.md`](./skills/review-animations/SKILL.md) for motion review
4. Choose a SevenDesign category skill, preset, archetype, and prompt from [`prompt-packs/`](./prompt-packs)

### Option 2: Use it in a real frontend project

1. Read [`quickstart/USE-IN-PROJECT.md`](./quickstart/USE-IN-PROJECT.md)
2. Copy files from [`examples/`](./examples)
3. Apply the token rules from [`TOKENS.md`](./TOKENS.md)

### Option 3: Choose a ready-made direction first

Open [`quickstart/CHOOSE-YOUR-STACK.md`](./quickstart/CHOOSE-YOUR-STACK.md)
