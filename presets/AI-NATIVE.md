# Preset: AI_NATIVE

- Flavor: `Developer Dark` + `Cinematic Future`
- Accent: `Signal Emerald` or `Velocity Purple`
- Surface: dark shell with raised spotlight modules
- Typography: strong display + mono accents
- Motion: staged hero reveal, subtle hover energy
- Base stack: `tailwindcss` + `shadcn/ui` + `radix ui`
- Optional enhancement: `reactbits` for hero and showcase sections

## Best For

- AI chat products
- agent builders
- model platforms
- prompt workspaces
- multimodal creative tools

## Avoid

- warm light SaaS treatment
- excessive enterprise table density on the homepage
- playful illustrations that reduce technical credibility
