# Preset: DEVTOOL_PRO

- Flavor: `Developer Dark` + `Data Dense Enterprise`
- Accent: `Infra Blue` or `Signal Emerald`
- Surface: restrained dark shell, strong border hierarchy, low decorative noise
- Typography: `Geist` or `Inter` with disciplined monospace support
- Motion: near-instant feedback with subtle staged reveals in marketing only
- Base stack: `tailwindcss` + `shadcn/ui` + `radix ui`
- Selective enhancement: `ant-design` for tables, filters, date pickers, and dense admin flows

## Best For

- IDE-like products
- observability and backend tooling
- API platforms
- infra control planes
- analytics-heavy dashboards

## Avoid

- overusing cinematic gradients inside operational views
- excessive card radius in dense modules
- homepage marketing behavior leaking into tables and forms
