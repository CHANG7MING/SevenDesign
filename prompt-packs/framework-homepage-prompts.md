# Framework Homepage Prompts

## Prompt: Productized Design Framework Homepage

```text
Use the attached SevenDesign library as the system source of truth.

Goal:
Design a homepage for a public-facing design framework / agent skill product that feels like a real product, not just a repository landing page.

Requirements:
- Follow DESIGN.md and TOKENS.md
- Use the PRODUCTIZED_FRAMEWORK direction
- Blend Vercel + Stripe + Linear influence
- Strong hero, stronger post-hero rhythm, clear product framing
- Include install or usage entry points, but do not let the page feel documentation-first
- Avoid generic SaaS cards and generic open-source repo layouts
- Make it feel premium, specific, and memorable

Sections:
- hero
- proof or adoption strip
- skills / modules section
- examples or showcase section
- install / getting started
- FAQ or final CTA
```
