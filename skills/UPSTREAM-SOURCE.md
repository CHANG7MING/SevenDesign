# Upstream source

The skills in these directories are vendored from [`attentiondotnet/emilkowalski_skills`](https://github.com/attentiondotnet/emilkowalski_skills), an MIT-licensed collection of design-engineering skills:

- [`emil-design-eng/`](./emil-design-eng/): design engineering, UI polish, component craft, and motion decisions
- [`apple-design/`](./apple-design/): fluid interfaces, gestures, springs, momentum, typography, and reduced motion
- [`animation-vocabulary/`](./animation-vocabulary/): a precise vocabulary for describing motion
- [`review-animations/`](./review-animations/): strict animation review with [`STANDARDS.md`](./review-animations/STANDARDS.md)

SevenDesign keeps the upstream skill bodies intact and adds local orchestration in [`design-core/SKILL.md`](./design-core/SKILL.md). When upstream changes, update the vendored directories deliberately and re-run the local link and frontmatter checks.

The [`team-mode/`](./team-mode/) skill is vendored from [`oil-oil/codex-team-mode`](https://github.com/oil-oil/codex-team-mode) and extended only with the SevenDesign routing reference.

The upstream license notice is preserved in [`EMILKOWALSKI-LICENSE.txt`](./EMILKOWALSKI-LICENSE.txt).

The Team Mode license notice is preserved in [`TEAM-MODE-LICENSE.txt`](./TEAM-MODE-LICENSE.txt).
