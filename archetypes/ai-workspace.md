# Archetype: AI Workspace

- Purpose: support prompting, generation, orchestration, evaluation, and result editing
- Audience: end users, analysts, creators, builders, operators
- Density: medium
- Flavor mix: `Developer Dark` or `Friendly SaaS` with `Cinematic Future` support
- Best themes: `AI_NATIVE`, `CREATIVE_MOTION`
- Avoid: purely brochure-like composition or purely raw admin framing

## Layout

- Header: context, model selector, project scope, or global actions
- Main grid: left context rail, main conversation/canvas, optional right inspector
- Side content: prompts, assets, run history, parameters, evaluation panels
- Footer / close: persistent input composer or action bar

## Dominant Components

- Prompt composer
- Conversation or result stream
- Parameter controls
- Asset panel
- Command palette or slash action system

## Motion

- Entrance style: calm reveal with focus on the active work area
- Hover style: card, attachment, and action affordances
- Scroll behavior: preserve context and input continuity

## Content Rhythm

- Opening: task context and ready state
- Middle: prompt, generation, refinement, comparison
- Closing: export, reuse, automate, or continue
