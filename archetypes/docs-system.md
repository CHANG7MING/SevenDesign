# Archetype: Docs System

- Purpose: present product, API, or knowledge content with high reading comfort and navigational clarity
- Audience: developers, operators, evaluators, customers, internal teams
- Density: medium
- Flavor mix: `Editorial Minimal` + `Developer Dark` or `Friendly SaaS`
- Best themes: `DEVTOOL_PRO`, `SAAS_WARM`, `FINTECH_TRUST`
- Avoid: generic markdown dump or detached marketing-site styling

## Layout

- Header: compact top nav with search and version context
- Main grid: left navigation, central reading column, optional right table of contents
- Side content: section nav, changelog links, related guides, code references
- Footer / close: previous/next docs navigation and contextual CTA

## Dominant Components

- sidebar navigation
- content blocks
- code blocks
- callouts
- tabs or examples

## Motion

- Entrance style: minimal and fast
- Hover style: links, nav items, code actions
- Scroll behavior: sticky sidebars and clear reading anchor states

## Content Rhythm

- Opening: title, summary, install or context
- Middle: structured reference and examples
- Closing: next steps, related pages, support CTA
