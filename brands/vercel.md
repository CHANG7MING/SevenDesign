# Brand Recipe: Vercel

- Category: Developer platform / deployment infrastructure
- Primary references: Vercel, Linear, Raycast
- Core mood: precise, quiet, premium, technical
- Primary accent: monochrome with optional `Infra Blue`
- Secondary accent: restrained cool gray or dim blue
- Background direction: black, graphite, deep neutral
- Typography signal: sharp sans serif with disciplined mono accents
- Surface style: flat-dark with subtle borders and sparse elevation
- Motion character: fast, clean, nearly invisible unless instructional
- UI density: medium
- Best use cases: AI infra, deployment consoles, devtools, documentation
- Avoid: oversaturated gradients, playful illustration, fluffy marketing language

## Borrowed Signals

- Signal 1: heroic restraint with strong whitespace
- Signal 2: developer legitimacy through shell-like UI cues
- Signal 3: highly polished but understated interactions

## Component Implications

- Buttons: compact, high-contrast, minimal radius, strong hover clarity
- Cards: dark planes with subtle borders instead of heavy shadows
- Navigation: slim, stable, highly scannable
- Data displays: monochrome-first with one accent reserved for key signals
- Marketing sections: bold typography and product proof over decorative spectacle

## Hero Guidance

- Headline style: concise, declarative, high confidence
- Visual direction: product shell, code surface, deployment graph, or infra scene
- CTA tone: direct and utilitarian
- Motion note: staggered text + controlled spotlight, no theatrical loops

## Inner Page Guidance

- Dashboard/workspace: align to dense but breathable dark UI
- Docs/content: narrow reading column with precise code blocks
- Forms/settings: compact spacing, strong label contrast, no soft pastel states
