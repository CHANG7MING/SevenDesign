# Brand Recipe: Supabase

- Category: backend platform / database developer tooling
- Primary references: Supabase, Vercel, Stripe
- Core mood: open, technical, modern, high-trust
- Primary accent: `Signal Emerald`
- Secondary accent: cool neutral or `Infra Blue`
- Background direction: dark technical surfaces with clean documentation whites
- Typography signal: modern sans with restrained mono accents
- Surface style: crisp panels, subtle glow, low-noise data surfaces
- Motion character: calm, polished, capability-first
- UI density: medium
- Best use cases: backend products, auth platforms, database tooling, AI infra
- Avoid: playful consumer softness, over-cinematic motion, cluttered enterprise chrome

## Borrowed Signals

- Signal 1: developer credibility without looking cold
- Signal 2: green accent used as precision, not decoration
- Signal 3: docs and product surfaces feel part of one system

## Component Implications

- Buttons: strong primary contrast with emerald authority
- Cards: flat-to-raised dark panels with crisp borders
- Navigation: clear docs + product duality
- Data displays: readable, compact, high-signal
- Marketing sections: feature proof and code surfaces over abstract claims

## Hero Guidance

- Headline style: practical confidence
- Visual direction: database console, auth flow, SQL or API scene
- CTA tone: direct and builder-friendly
- Motion note: subtle staged reveal, no theatrical loops

## Inner Page Guidance

- Dashboard/workspace: developer-first, dense but breathable
- Docs/content: code comfort and high clarity
- Forms/settings: compact and reliable
