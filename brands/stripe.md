# Brand Recipe: Stripe

- Category: Fintech / platform infrastructure
- Primary references: Stripe, Framer, Cohere
- Core mood: sophisticated, fluid, modern, high-trust
- Primary accent: `Velocity Purple`
- Secondary accent: `Infra Blue`
- Background direction: deep indigo, white, and clean gradient transitions
- Typography signal: elegant sans serif with polished editorial hierarchy
- Surface style: elevated but smooth, often gradient-aware
- Motion character: fluid and sequenced, visible but never noisy
- UI density: medium
- Best use cases: payments, APIs, premium SaaS, pricing-heavy sites
- Avoid: harsh enterprise heaviness, raw terminal aesthetics, crowded feature grids

## Borrowed Signals

- Signal 1: gradient sophistication without color chaos
- Signal 2: feature explanation through visual sequencing
- Signal 3: trust reinforced by polish and structural clarity

## Component Implications

- Buttons: premium contrast with soft but confident shape language
- Cards: layered surfaces with refined highlight treatment
- Navigation: clean top nav with polished hover and disclosure states
- Data displays: financial clarity with carefully tuned accent usage
- Marketing sections: motion-led storytelling with crisp proof blocks

## Hero Guidance

- Headline style: aspirational but specific
- Visual direction: layered product modules, gradient field, API or workflow diagram
- CTA tone: calm confidence
- Motion note: guided sequence, floating relation, clean interpolation

## Inner Page Guidance

- Dashboard/workspace: preserve polish without hurting task clarity
- Docs/content: bright, structured, code-friendly, minimal clutter
- Forms/settings: highly legible, semantic, confidence-inspiring
