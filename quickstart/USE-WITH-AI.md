# USE-WITH-AI

This is the shortest workflow for using the library with ChatGPT, Claude, Gemini, Cursor, or any code-generation assistant.

## Minimal Workflow

1. Give the AI [`DESIGN.md`](../DESIGN.md)
2. If implementation matters, also give it [`TOKENS.md`](../TOKENS.md)
3. Pick one prompt from [`prompt-packs/core-prompts.md`](../prompt-packs/core-prompts.md)
4. If needed, add one brand recipe and one archetype recipe

## Recommended Attachments

### For design direction only

- [`DESIGN.md`](../DESIGN.md)
- one brand recipe
- one archetype

### For real frontend implementation

- [`DESIGN.md`](../DESIGN.md)
- [`TOKENS.md`](../TOKENS.md)
- [`examples/tailwind.config.ts`](../examples/tailwind.config.ts)
- [`examples/globals.css`](../examples/globals.css)
- one or more example components from [`examples/`](../examples)
